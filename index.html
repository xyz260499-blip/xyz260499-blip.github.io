Kensho Shorts

A private tool that prepares short videos for the YouTube channel “Bas Kar Bhai” (formerly Kensho Gaming).

What it does

Kensho Shorts runs on the channel owner's own computer. It finds highlight moments in long videos, edits them into vertical Shorts with captions, and uploads them to the owner's own YouTube channel as private videos, so the owner can review them before publishing.

Who can use it

This is a personal tool used only by the channel owner. It is not offered to the public, and no other users sign in to it.

Google / YouTube data

The tool uses the YouTube Data API only to upload videos to, and read basic details of, the owner's own channel. See the Privacy Policy for details.
