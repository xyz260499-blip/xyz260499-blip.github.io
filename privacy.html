What Google data it accesses

With the owner's permission, through Google sign-in, it uses these YouTube Data API scopes:

How the data is used

The data is used only to upload the owner's videos and to check that the correct channel is signed in. It is not used for advertising, profiling or any other purpose.

Storage and sharing

The sign-in token is stored only on the owner's own computer. No Google user data is sent to, stored on, or shared with any third party or server operated by this tool. No data from any other person is collected.

Removing access

The owner can revoke this tool's access at any time at myaccount.google.com/permissions, and can delete the token file from their computer.

Google API Services User Data Policy
